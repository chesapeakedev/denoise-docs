`dn` is the CLI core that powers denoise workflows: authenticate with GitHub, prepare repositories, dispatch automation, and run kickstart to plan and implement issues. Start with [dn installation](/dn-cli/installation/), then use the denoise app docs when you want the product UI on top of those workflows.
